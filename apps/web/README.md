# ReaganXS Web App

Full-featured web version of ReaganXS — Hybrid Edge-Cloud Video Processor.

## Philosophy
**Compress Aggressively First, Restore Selectively & Intelligently**

## Tech Stack
- Next.js 15 (App Router)
- TypeScript
- Tailwind + shadcn/ui
- Cloudflare Pages deployment

## Key Features
- Smart Routing (Client + Server)
- Progressive Tiering (MVP → Full Web)
- Virality Savings Cards
- Power-aware recommendations
