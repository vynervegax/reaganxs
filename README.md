# ReaganXS

Hybrid Edge-Cloud Video Processing Platform  
**"Compress Aggressively First, Restore Selectively & Intelligently"**

## Core Philosophies
- Power & Efficiency First
- Progressive Tiering (MVP → Web → Desktop)
- Hybrid Intelligence (Smart Routing)
- Community-Driven Model Improvement

## Tech Stack
- **Frontend**: Next.js 15 (Web + MVP)
- **Desktop**: Tauri 2 + Rust
- **Backend**: Node.js + Express + MongoDB
- **Processing**: FFmpeg (SVT-AV1), ONNX Runtime, libvmaf
- **Storage**: Cloudflare R2
- **Deployment**: Cloudflare Pages + Railway
